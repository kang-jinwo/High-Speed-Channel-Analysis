# 1단계 — 노드 해석과 행렬 (선형대수)

> 실행: `python experiments/s1_dc.py` · 코드: `minispice/circuit.py`, `minispice/analysis.py`

## 직관 먼저

- 저항 회로를 푼다는 건 결국 **연립일차방정식 하나**를 푸는 일이다. 노드마다 KCL 한 줄.
- 해가 유일하지 않은 회로(어디에도 묶이지 않은 노드)는 방정식에서 **det = 0** 으로 드러날 것이다.
  전압은 "차이"만 의미가 있으니, 기준(접지)과 끊긴 덩어리는 통째로 몇 V 를 더해도 식이 성립한다.

## 손풀이: 브리지 회로

```
        a ──R1(1k)── b ──R2(2k)── 0
 10 V   │            │
        │          R5(5k)
        │            │
        └──R3(3k)── c ──R4(1k)── 0
```

$v_a = 10$ 은 알고 있으니 미지수는 $v_b, v_c$. 각 노드에서 **나가는 전류의 합 = 0**:

$$\frac{v_b-10}{1\text{k}}+\frac{v_b}{2\text{k}}+\frac{v_b-v_c}{5\text{k}}=0,\qquad
\frac{v_c-10}{3\text{k}}+\frac{v_c}{1\text{k}}+\frac{v_c-v_b}{5\text{k}}=0$$

첫 식에 10k, 둘째 식에 15k 를 곱해 정리하면

$$\begin{bmatrix}17&-2\\-3&23\end{bmatrix}\begin{bmatrix}v_b\\v_c\end{bmatrix}=\begin{bmatrix}100\\50\end{bmatrix},
\qquad \det = 17\cdot23-(-2)(-3)=385$$

크래머 공식:

$$v_b=\frac{100\cdot23+2\cdot50}{385}=\frac{2400}{385}=6.234\ \text{V},\qquad
v_c=\frac{17\cdot50+3\cdot100}{385}=\frac{1150}{385}=2.987\ \text{V}$$

**행렬의 모양에서 읽히는 것**
- 대각 성분 = 그 노드에 붙은 컨덕턴스의 합, 비대각 성분 = −(두 노드 사이 컨덕턴스). → 회로도만 보고 바로 쓸 수 있다.
- 대칭이다(스케일링 전 기준). 수동 소자만 있으면 항상 그렇다.
- 이 규칙을 소자 하나당 "도장 찍기(stamp)"로 바꾼 것이 시뮬레이터의 `build()`.

## 전압원은 어떻게 넣나 — 수정 노드 해석(MNA)

전압원은 "전류가 얼마든 전압이 고정"이라 컨덕턴스로 못 쓴다. 그래서 **전압원 전류 $i_V$ 를 미지수에 추가**하고
식 한 줄($v_a - v_b = V$)을 더한다. 브리지 회로는 미지수가 $[v_a, v_b, v_c, i_{V1}]$ 인 4×4 가 된다.

$$\begin{bmatrix}G_{nn}&A\\A^{\mathsf T}&0\end{bmatrix}\begin{bmatrix}v\\i_V\end{bmatrix}=\begin{bmatrix}i_s\\V\end{bmatrix}$$

## det = 0 인 회로

`R3 x y 1k` 처럼 접지와 이어지지 않은 저항을 넣으면 $v_x, v_y$ 행은

$$\begin{bmatrix}g&-g\\-g&g\end{bmatrix}\begin{bmatrix}v_x\\v_y\end{bmatrix}=\begin{bmatrix}0\\0\end{bmatrix}$$

두 행이 서로 −1 배 → 일차종속 → det = 0. 영공간 벡터는 $[1,1]^{\mathsf T}$, 즉 "둘을 같이 올려도 된다".
시뮬레이터는 SVD 로 **영공간 벡터에서 0 이 아닌 성분**을 찾아 어느 노드가 떠 있는지 이름으로 알려 준다.
(실제 판정은 det 값 대신 rank 로 한다. det 는 행렬 크기와 단위에 따라 값이 너무 크게 변해서 "0 에 가깝다"의 기준을 잡기 어렵다.)

전압원 두 개를 병렬로 묶으면 반대로 **전류**가 정해지지 않는다(영공간이 $i_{V1}, i_{V2}$ 를 가리킨다).
